# Maná do Céu — atualização visual V1.2

A página pública foi redesenhada usando como referência o conceito visual enviado pelo cliente:

- azul + laranja como cores principais;
- hero com a chamada “Seu almoço, com sabor de casa” e imagem da marmita;
- navegação Cardápio / Como pedir / Contato;
- categorias em cartões: Pratos do dia, Bebidas e Sobremesas;
- cards do cardápio maiores e com CTA laranja;
- experiência mobile com menu compacto e acesso rápido ao pedido;
- seções “Como pedir” e chamada final para o carrinho;
- funcionalidades existentes do V1.1 preservadas: admin, cardápio diário, categorias, carrinho, checkout, WhatsApp e imagem de status.

Observação: o pacote não redistribui arquivos de fonte; o CSS usa fontes do sistema como fallback.
